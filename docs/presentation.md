## 화면 네 장

1. **무엇인가** — 기업 소개 + 회원·게시판, React SPA를 Spring Boot가 한 서버에서 서빙
2. **어떻게 만들었나** — 클린 아키텍처, 바깥 → 안쪽, 포트에 구현을 꽂는 방식
3. **무엇을 할 수 있나** — 본인인증 가입, 기업 확인, 소셜 로그인, 자유 / QnA / 자료실
4. **어떻게 지키나** — 유료 WAF 없이 7겹. 정상 사용자는 캡차 퀴즈가 없다

## 대본 (그대로 읽으면 약 90초)

안녕하세요. Hexaq는 기업 소개 홈페이지와 회원·게시판을 한 서버에서 제공하는 웹 애플리케이션입니다.

구조는 클린 아키텍처입니다. 화면은 React, 서버는 Spring Boot입니다. 의존성은 바깥에서 안쪽으로만 흐르고, 도메인에는 규칙만, 인프라에는 DB·메일·SMS 구현만 둡니다. 프론트도 페이지는 화면만 조립하고, API 호출은 훅과 서비스로 분리했습니다.

기능은 가입부터입니다. 가입 전 이메일 또는 휴대폰 인증이 필요하고, 기업 회원은 국세청 사업자 확인을 거칩니다. Google, Kakao, GitHub 소셜 로그인을 지원하고, 자유게시판, QnA, 자료실을 제공합니다.

보안은 유료 솔루션 없이 일곱 겹입니다. HMAC으로 API 직접 호출을 막고, 레이트 리밋·캡차·허니팟·일회용 메일로 봇을 거릅니다. 이메일을 DI로 써서 한 메일 한 계정을 강제하고, 가입 직후 이상 탐지로 매크로 쓰기를 제한합니다. 사람은 캡차 퀴즈를 보지 않습니다.

정리하면, Hexaq는 교체 가능한 인프라 위에 회원·게시판을 올리고, 사이트는 열어 두되 API 남용은 일곱 겹으로 막는 구성입니다. 이상입니다.
